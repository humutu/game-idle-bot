# templates 目录

这里放**你自己裁的模板图**。仓库不附带任何游戏截图（版权原因，而且模板必须和你的游戏界面一致）。

模板就是一张小截图：程序在游戏画面里按像素找它，找到后点击它（或按配置偏移点击）。
尺寸不用和下面的参考值完全一致。裁剪工具会在模板旁边写一个同名 `.json` 记录当时的窗口宽度，
运行时按「当前窗口宽度 ÷ 参考宽度」自动缩放模板，所以之后改窗口大小一般不用重裁。

## 裁剪步骤

1. 打开游戏，把窗口调到一个顺手的尺寸（例如 548×1056，不要最大化）。这个宽度会被记进 `.json`，后面改大小也能自动缩放。
2. 截一张整个窗口的图：

   ```bat
   .venv\Scripts\python.exe -m gamebot.tools snapshot --window 小游戏
   ```

   也可以先用 `windows` 命令确认标题：

   ```bat
   .venv\Scripts\python.exe -m gamebot.tools windows --filter 小游戏
   ```

3. 把游戏切到目标界面，再运行：

   ```bat
   .venv\Scripts\python.exe -m gamebot.tools crop --image captures\frame_你的时间.png --name levelup_banner
   ```

   弹出的窗口里拖动鼠标框住目标，按 Enter 保存，按 C 取消。
4. 换下一个界面，重复步骤 2–3，直到 12 个模板都齐了。
   每张模板旁边都会多一个同名 `.json`（例如 `levelup_banner.json`），是 `crop` 自动写的参考宽度，不要删。
5. 回到目标界面跑一次识别验证：

   ```bat
   .venv\Scripts\python.exe -m gamebot.tools probe
   ```

   看输出里的分数：达到阈值的规则会标「命中」，同时会在 `captures\probe_*.png` 里画框标出位置。

## 裁剪要点

- **框住文字或图标**，不要只框一块纯色。纯色按钮会在别处误匹配，`crop` 命令会提示「接近纯色」。
- 横幅类模板框得紧凑一点，别把会动的背景也框进来。
- 不要把鼠标指针截进去。
- 窗口大小改变后一般不用重裁：程序按 `.json` 里的参考宽度自动缩放模板。宽度差距很大（比如 400 和 900 之间换）会因插值变模糊，建议按新尺寸重裁。
- 显示器 DPI 缩放改变后，模板可能匹配不上，回到原 DPI 或重新裁剪即可。
- 如果不需要某些玩法，可以把 `config.yaml` 里对应的规则删掉，模板也就不用裁。
