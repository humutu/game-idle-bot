# 模板制作与校准

这个工具没有接入游戏接口，它做的事只有两件：

1. 截取游戏窗口的客户区画面；
2. 用 `cv2.matchTemplate` 在画面里找模板图，找到就点它。

所以「脚本能不能用」几乎完全取决于模板图裁得好不好。本文按界面逐个说明怎么裁、怎么验证。

## 一、开始之前

- 游戏窗口必须**窗口化**，不要最大化，不要最小化。
- 窗口大小可以变化：模板是按像素匹配的，但 `crop` 会在模板旁边写一个同名 `.json` 记录裁剪时的窗口宽度，运行时按比例自动缩放模板。
- 显示缩放（DPI）也保持一致，例如一直用 100% 或 125%。DPI 变化不在自动缩放范围内。
- 程序是 Per-Monitor DPI Aware 的，截图和点击坐标都按物理像素计算。

先用 `windows` 命令确认窗口标题和尺寸：

```bat
.venv\Scripts\python.exe -m gamebot.tools windows --filter 小游戏
```

它输出句柄、进程名、窗口尺寸和标题。记下尺寸，之后就用这个尺寸挂机。

## 二、基本流程

以「升级选卡」为例：

1. 游戏走到升级选卡界面。
2. 截整窗：

   ```bat
   .venv\Scripts\python.exe -m gamebot.tools snapshot --window 小游戏
   ```

3. 裁剪：

   ```bat
   .venv\Scripts\python.exe -m gamebot.tools crop --image captures\frame_20260101_120000.png --name levelup_banner
   ```

   弹出窗口后，用鼠标框住横幅标题，按 **Enter** 保存，按 **C** 取消。
   命令会打印自匹配分数和参考宽度；如果提示「接近纯色」，说明框得太平，把文字或图标框进来重裁。
   保存时会在 `templates` 里多写一个同名 `.json`（例如 `levelup_banner.json`），记录裁剪时的窗口宽度，运行时靠它自动缩放模板，不要删。
4. 换下一个界面，重复 2–3。

`crop` 不指定 `--image` 时会自动用 `captures` 里最新的一张截图，但建议显式指定，避免裁错画面。

## 三、各界面裁什么

### 1. 主界面

- `start_battle.png`：底部「开始战斗」大按钮，整个按钮（底色+文字）一起框。
- `global_enter.png`：「全球联防」标题文字。这个模板的点击位置不是中心，配置里用 `point_rel: [2.41, 4.63]` 从模板左上角向右偏移 2.41 个模板宽、向下 4.63 个模板高，落到右侧的「进入」上。改了裁剪范围要重新核对这两个倍数。
- `global_start.png`：联合防御大厅底部的「开始挑战」按钮。

### 2. 普通升级（三选一）

- `levelup_banner.png`：界面顶部的升级横幅。只框横幅本身，别把三张卡带进去。
- 三张卡的点击位置和标题识别区域在配置里按窗口比例写死：

  ```yaml
  slots: [[0.178, 0.570], [0.500, 0.570], [0.822, 0.570]]
  title_boxes:
    - [0.035, 0.458, 0.322, 0.497]
    - [0.358, 0.458, 0.640, 0.497]
    - [0.678, 0.458, 0.966, 0.497]
  ```

  如果游戏界面布局和示例不同，用截图量一下比例再改。

### 3. 精英 / BOSS 选卡

- `select_banner.png`：精英关卡开局的「选择卡牌」横幅。卡牌位置、标题区域和普通升级一样。

### 4. 额外机会

- `extra_chance_banner.png`：「额外机会」标题横幅。
- `card_back.png`：一张未翻开的卡背，整张卡框进去（含边框和背面的图案）。
- `acquire_btn.png`：「获得」黄色按钮。对应规则默认禁用，见 README 的说明。

`draw_cards` 动作会在画面里反复找卡背，每点一张重新截图，最多点 `max_picks` 张；剩下的卡会重排，所以不能写死点位。

### 5. 结算 / 新阶段

- `again_btn.png`：结算页「再来一次」。
- `settle_back.png`：胜利结算页左下「返回」。右边通常还有「双倍奖励」，**不要框进去**。
- `newstage_banner.png`：新阶段开场横幅。点击位置用 `point: [0.50, 0.94]` 定位到底部「点击此处跳过」。

## 四、验证

在目标界面运行：

```bat
.venv\Scripts\python.exe -m gamebot.tools probe
```

输出示例：

```
截图尺寸 548x1056，标注图：captures\probe_20260101_120500.png

  [命中]       升级选卡        分数 0.991  阈值 0.85
  [未达阈值]   额外机会-多抽    分数 0.612  阈值 0.85
  ...
```

- 「命中」= 当前界面会被正确处理。
- 输出里如果有一行「缩放 0.793」，表示窗口宽度是参考宽度的 0.793 倍，模板被自动缩小后再匹配；缩放偏离 1 越多，分数越容易略降。
- 分数离阈值只差一点点（例如 0.84 / 0.85）：重新裁得更紧凑，或把阈值下调 0.02–0.03。
- 某个模板在**不该出现的界面**上分数很高（例如结算页上「开始战斗」0.91）：说明模板太通用，把阈值调高，或干脆删掉这条规则（示例里 `start_battle` 的阈值就是因此调到 0.95）。

再用 dry-run 演练一遍，只看不点：

```bat
.venv\Scripts\python.exe main.py --dry-run
```

## 五、常见问题

**窗口大小变了怎么办？**
一般不用处理。模板旁边的 `.json` 记录着裁剪时的窗口宽度，运行时按「当前宽度 ÷ 参考宽度」自动缩放。
宽度变化特别大（例如 400 和 900 之间）时插值会让模板变模糊，这时按新尺寸重裁一遍更稳；老模板没有 `.json` 时按 `defaults.ui_width` 兜底。

**同一套模板换台电脑分数就掉了？**
检查显示缩放（DPI）和游戏内分辨率设置是否一致。

**截图是黑屏 / 画面卡住？**
后台模式用的是 `PrintWindow`，极小化或完全被其它窗口遮挡时，部分客户端会返回黑帧。保持窗口可见（可以被部分遮挡，但别完全盖住、别最小化）。

**裁剪窗口里按 Enter 没反应 / 变成空白？**
这是 OpenCV 的选图窗口：先拖出选框再按 Enter，按 C 取消，框太小会被取消。

**OCR 不认卡名？**
Windows 设置 → 时间和语言 → 语言 → 中文(简体) → 可选功能，安装 OCR 语言包。也可以在网页里取消对应卡牌，让程序改点兜底位置。
